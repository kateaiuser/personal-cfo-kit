# CFO: вход

## Pre-flight (каждый раз, до любой работы)

1. Прочитай `CLAUDE.md`: роль, границы, правила расчётов.
2. Прочитай `context.md`. Если там ещё плейсхолдеры, первая задача: заполнить его вместе с владельцем, не больше 5 вопросов за раз.
3. Прочитай `plan/STATUS.md` и последние записи `plan/decisions.md`.
4. Сравни файлы в `inbox/` (кроме README.md) с `ledger/sources.csv`. Новые файлы назови одной строкой и предложи разобрать (`intake`).
5. Если в `plan/STATUS.md` нет записи о проверке защиты, начни с `selfcheck`.
6. Выбери модуль по таблице и прочитай его целиком.

## Всегда

- Цифры только из `ledger/` и документов. Нет данных: скажи, каких.
- Ответ владельцу начинай с главного: цифра, вывод, следующий шаг.
- В конце сессии: ритуал из `CLAUDE.md`.
