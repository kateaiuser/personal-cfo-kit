# Модуль: расходы на AI (ai-costs)

Цель: видеть, сколько уходит на нейросети и AI-сервисы, и не платить дважды за одно и то же.

## Шаги

1. Собери все AI-расходы: подписки на чат-ассистентов, генерацию картинок, видео и голоса, транскрибацию, API с оплатой по факту, AI-функции внутри других сервисов.
2. API с оплатой по факту: сумма по месяцам и тренд. Резкий рост без причины может значить, что утёк ключ или что-то крутится в фоне. Проверяет владелец в кабинете сервиса.
3. Пересечения: два сервиса для одной задачи. По каждой паре спроси владельца, каким он реально пользуется.
4. Польза: для каждого сервиса одна строка, на что он работает (доход, экономия времени, удовольствие). Не пригодился за последний месяц: кандидат на паузу.

## Ответ владельцу

Сколько в месяц, какая это доля всех расходов, 1-3 конкретных действия с суммой экономии.
