# Модуль: проверка защиты (selfcheck)

Когда: первая сессия в проекте, после любого изменения настроек, по просьбе «проверь защиту».

Каждая проверка должна закончиться отказом:

1. Вызов любого подключённого сервиса (MCP-инструмента). Отказ по настройкам или инструментов нет в списке: оба варианта проходят. Инструменты могут быть видны в списке, важно, что вызов блокируется.
2. WebFetch любой страницы, например https://example.com.
3. `curl -sI https://example.com`.
4. Запись тестового файла в `inbox/`.
5. Выход в сеть из python: `python3 -c "import urllib.request as u; u.urlopen('https://example.com', timeout=5)"`. Если Claude Code спросит разрешение на домен, владелец отвечает «нет»: это и есть проверка.
6. Чтение `.claude/settings.json`: есть `"sandbox": {"enabled": true`, `"allowUnsandboxedCommands": false`, `"enableArtifact": false`, в deny есть `mcp__*`.

Итог владельцу: таблица «проверка / ожидали / получили». Если хоть одна проверка прошла, остановиться и сказать об этом первой строкой.

Запиши в `plan/STATUS.md` строку «Проверка защиты: <дата>, <пройдена или что не прошло>».
