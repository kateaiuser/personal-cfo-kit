# Модуль: категории (categorize)

Цель: у каждой операции есть категория, и владелец видит, куда уходят деньги.

## Категории

Базовый набор, владелец может менять:

| Категория | Примеры |
|---|---|
| Жильё | аренда, ипотека, коммунальные, страховка жилья |
| Еда | продукты, кафе, доставка |
| Транспорт | машина, бензин, страховка, парковка, такси |
| Здоровье | страховка, врачи, аптека |
| Дети | школа, кружки, присмотр |
| Долги | проценты, комиссии, платежи по кредитам |
| Подписки | сервисы, приложения |
| AI и софт | нейросети, рабочие инструменты |
| Бизнес | расходы на работу и проекты |
| Налоги | налоговые платежи |
| Личное | одежда, красота, подарки, развлечения |
| Переводы | между своими счетами, не расход |

## Шаги

1. Сначала правила из `ledger/rules.csv`: продавец и категория.
2. Остальное разложи сам по описанию и продавцу.
3. Сомнительные строки собери в один список и спроси владельца разом, а не по одной.
4. Ответы, которые будут повторяться, запиши в `ledger/rules.csv`.
5. Отметь `recurring` и `scope` (личное или рабочее). Рабочие расходы и всё, что может быть важно для налогов, пометь `tax_tag`. Это метка для бухгалтера, а не вывод, что расход вычитается.

## Ответ владельцу

Топ-8 категорий за последний полный месяц: сумма и доля. Что удивило. Сколько строк ещё без категории.
