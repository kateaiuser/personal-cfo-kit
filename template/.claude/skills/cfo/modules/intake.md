# Модуль: разбор выписок (intake)

Цель: все операции со всех счетов в одной таблице `ledger/transactions.csv`, без дублей и с понятным типом каждой строки.

## Вход

Новые файлы в `inbox/`, которых нет в `ledger/sources.csv`.

## Схема таблицы

| Поле | Что в нём |
|---|---|
| `id` | уникальный номер строки |
| `date` | дата операции, YYYY-MM-DD |
| `account` | счёт или карта: название и последние 4 цифры |
| `institution` | банк или сервис |
| `description` | описание из выписки как есть |
| `merchant` | продавец, очищенный от мусора |
| `amount` | сумма: приход с плюсом, расход с минусом |
| `currency` | валюта |
| `type` | income, expense, transfer, refund, fee, interest, payout |
| `category`, `subcategory` | категория (модуль `categorize`) |
| `recurring` | yes, если платёж повторяется |
| `scope` | personal или business |
| `tax_tag` | метка для бухгалтера, если строка может быть важна для налогов |
| `source_file` | из какого файла строка |
| `note` | пояснения |

## Шаги

1. Определи формат файла: банк, колонки, знак сумм (у одних банков расход с минусом, у других отдельной колонкой), формат дат.
2. Приведи к схеме кодом на python, стандартной библиотекой.
3. Дубли: одна операция из двух файлов (выписка и выгрузка карты, пересекающиеся периоды). Ключ: дата, сумма, счёт, описание. Сомнительные дубли не удаляй, а помечай в `note`.
4. Переводы между своими счетами: пара «минус здесь, плюс там» на ту же сумму в пределах 3 дней, `type = transfer`. Это не доход и не расход. Оплата кредитной карты с текущего счёта тоже перевод, если покупки по этой карте есть в таблице: расход здесь это сами покупки, проценты и комиссии.
5. Платёжные сервисы (Stripe, PayPal, Square и похожие): продажи, комиссии и выплаты на счёт отдельными строками. В доход идут продажи, комиссия в расход, выплата на банковский счёт это перевод. Иначе доход посчитается дважды или комиссия потеряется.
6. Возвраты (`refund`) привяжи к исходной покупке, если видно.
7. Запиши файл в `ledger/sources.csv`: счёт, период, число строк, дата разбора.

## Контроль

- Сумма операций за период равна разнице конечного и начального остатка по выписке. Не сходится: найди где и скажи владельцу.
- Между выписками одного счёта нет пропущенных дней.
- Ни одной строки без `type`.

## Ответ владельцу

Сколько файлов и строк разобрано, за какой период, что не сошлось, какие вопросы. Потом предложи `categorize`.

В конце пересобери дашборд (`dashboard.md`) и одной строкой скажи, что в нём изменилось.
