# Изоляция: закрыть финансовую папку от остальных проектов

Настройки внутри финансовой папки защищают её изнутри: агент в ней не выходит в сеть и не читает остальной диск. Но любой другой проект Claude Code на этом же компьютере по умолчанию может прочитать финансовую папку. Её нужно закрыть и снаружи.

## 1. Запрет в других проектах

В `.claude/settings.json` каждого проекта, где работают агенты с почтой, браузером или коннекторами, добавь в `permissions.deny`:

```json
"Read(//Users/ИМЯ/Finance/**)",
"Edit(//Users/ИМЯ/Finance/**)",
"Read(//Users/ИМЯ/.claude/projects/-Users-ИМЯ-Finance/**)",
"Edit(//Users/ИМЯ/.claude/projects/-Users-ИМЯ-Finance/**)",
"Bash(*Finance*)"
```

- `ИМЯ` это имя пользователя macOS, `Finance` это имя твоей папки. `//` в начале означает абсолютный путь.
- Вторая пара правил закрывает переписку: Claude Code хранит разговоры обычным текстом в `~/.claude/projects/`, имя папки там совпадает с путём проекта, где `/` заменены на `-`.
- **Не клади эти правила в `~/.claude/settings.json`.** Запрет оттуда действует везде, и агент в самой финансовой папке перестанет её читать.

Честная оговорка: правила блокируют инструменты, но скрипт, который собирает путь в коде, их обойдёт. Полную стену даёт только песочница (`sandbox`) в том проекте. Без неё это сильный барьер, а не гарантия.

## 2. Серверы MCP из домашней папки

Если в домашней папке есть `~/.mcp.json`, его серверы могут стартовать в каждой сессии, открытой в подпапке, включая финансовую. Отключи автозапуск в `~/.claude/settings.local.json`:

```json
"enableAllProjectMcpServers": false
```

Вызовы любых MCP-инструментов в финансовой папке и так запрещены правилом `mcp__*` из шаблона. Имена серверов, которые стартуют сами, можно добавить в `deniedMcpServers`.

## 3. Коннекторы claude.ai в десктоп-приложении

Приложение может показывать коннекторы claude.ai (почта, диск и другие) в списке инструментов сессии даже при `"disableClaudeAiConnectors": true`. Список не страшен: вызовы блокирует `mcp__*` в deny. Модуль `selfcheck` проверяет это при первом запуске.

## 4. Обучение и хранение

- В настройках приватности claude.ai выключи использование своих чатов для обучения моделей.
- Оценки ответов (палец вверх или вниз) и команды обратной связи отправляют разговор целиком. В финансовой папке ими не пользуйся. Шаблон отключает опросы обратной связи.
- Переписка лежит на диске обычным текстом. Включи шифрование диска (FileVault на macOS).
- В финансовой папке не заводи git: глобальные хуки и привычки легко отправят данные в удалённый репозиторий.
