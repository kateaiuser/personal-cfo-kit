# personal-cfo-kit

Набор для Claude Code, который превращает одну локальную папку в личного финдиректора: план выхода в плюс, подписки, счета, кредитная история, папка документов для бухгалтера. Банки и почту подключать не нужно: выгрузки кладутся в папку руками.

> Это не финансовая, налоговая или юридическая консультация. Агент считает деньги и готовит документы. Решения принимаешь ты, декларацию подаёт бухгалтер.

## Как это работает

Выгрузки из банков и карт (CSV или PDF) кладёшь в `inbox/`, открываешь папку в Claude Code и набираешь `/cfo`. Агент читает правила, твою цель и статус, видит новые файлы и выбирает нужный модуль.

| Модуль | Что делает |
|---|---|
| `intake` | сводит выписки в одну таблицу, находит дубли и переводы между своими счетами |
| `categorize` | раскладывает операции по категориям и запоминает правила |
| `subscriptions` | находит все регулярные списания, решение по каждому |
| `ai-costs` | считает расходы на AI-сервисы и пересечения между ними |
| `cash-plan` | план выхода в плюс: самая дорогая дыра, долги в двух порядках, сценарии, 8 недель |
| `weekly-check` | 15 минут в неделю: план и факт, 3 действия |
| `monthly-review` | закрывает месяц цифрами и правит план |
| `bills` | разбор счетов, скрипт торга с сервисами, спор по медицинским счетам |
| `purchase-check` | что крупная покупка сделает с планом |
| `net-worth` | активы и долги одной картиной |
| `tax-prep` | папка для бухгалтера: доходы, расходы, чек-лист, вопросы |
| `credit` | разбор кредитных отчётов, загрузка карт, ошибки для спора |
| `dashboard` | локальный HTML-дашборд, который ничего не грузит из сети |
| `safety` | как проверить сервис, прежде чем дать ему доступ |
| `selfcheck` | проверка, что защита папки работает |

Модули налогов и кредитной истории заточены под США. Язык набора русский.

## Защита

- **Без сети.** В `.claude/settings.json` запрещены WebFetch, WebSearch, curl, wget, ssh, git, все MCP-инструменты и инструменты, которые отправляют файлы или уведомления наружу.
- **Песочница.** Агент читает только свою папку.
- **Исходники не трогаются.** `inbox/` только для чтения.
- **Без автопилота.** Авто-режим, артефакты и обратная связь выключены.
- **Без доступа к деньгам.** Агент не вводит пароли, SSN и номера карт, не подаёт налоги, не двигает деньги и не даёт инвестиционных советов.
- **Что видит модель.** Файлы остаются на компьютере, но то, что агент читает, попадает в разговор с моделью. Использование своих чатов для обучения выключи в настройках приватности claude.ai.

Закрыть папку от других проектов на этом же компьютере нужно отдельно: [docs/isolation.md](docs/isolation.md).

## Установка

Нужен Claude Code (в терминале или в десктоп-приложении).

```bash
git clone https://github.com/kateaiuser/personal-cfo-kit.git
cd personal-cfo-kit
./setup.sh ~/Finance
```

Дальше:

1. Закрой папку от других проектов: [docs/isolation.md](docs/isolation.md).
2. Открой `~/Finance` в Claude Code и набери `/cfo`. Первая сессия сама проверит защиту.
3. Положи в `inbox/` выписки за последние 3 месяца.

## Что внутри

```
template/                    то, что ставится в твою папку
  CLAUDE.md                  роль, границы, правила расчётов
  README.md                  что класть в inbox/ и чего не давать никогда
  context.md                 цель, доходы, обязательства (заполняется в первой сессии)
  .claude/settings.json      защита: запреты и песочница
  .claude/skills/cfo/        вход /cfo и 15 модулей
  inbox/ ledger/ plan/ tax/ tools/
docs/isolation.md            как закрыть папку от других проектов
setup.sh                     установщик
```

Скрипт дашборда агент пишет сам при первой просьбе, по описанию в модуле `dashboard`. Настройки рассчитаны на macOS.
